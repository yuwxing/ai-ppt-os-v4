## 二、制作过程还原（33 页流程）

1. **封面**（P1）——单元标题 + 课型 + 学校/教师署名 + 背景图。公开课必备署名。
2. **情境建立**（P3-4）——**Mike 是汕大外国学生**，想知道学校周边。用真实人物建立任务："How do we tell Mike about neighborhood of our school?"
3. **街名导入**（P5-6）——Longyan Street / Zhongshan Road / Bingang Street 真实地名 + 音标。
4. **句型呈现**（P7）——"There is a park on the way to my school. I can take a walk and do exercise there."
5. **听力任务1**（P8-9）——Listen：①put √ if we have the place，× if not；②match。表格列出 6 场所。
6. **句型操练 ×5**（P10-14）——"There is a ___ near here. We can ___." 逐一练：bank取钱/restaurant吃饭/hospital看病/police station求助/hotel住宿。
7. **听力任务2**（P16）——Listen and speak out：挖空对话补全。
8. **Pair work**（P17）——"Is there a ___ on ___ Street/Road?" 完成地图，**限时2分钟**。
9. **Chain Game**（P18-19）——接龙游戏（就近原则 principle of proximity），**限时1分钟**。
10. **情境推进**（P20）——学生不能带手机 → 引出 pay phone 主题。
11. **听力任务3**（P21）——Listen and match：Where is the pay phone?（方位匹配）
12. **方位介词讲解**（P22-23）——on/next to/between/in front of/across from + 中文释义。
13. **听力任务4**（P25）——Listen and fill in the blanks（2b）。
14. **Memory Test**（P26）——记忆挑战游戏。
15. **Group work**（P27-30）——"What neighborhood do you want?" 小组分工：**ask/answer/reporter/designer**，**限时10分钟**，产出"The neighborhood we want"。
16. **Summary**（P31）——总结。
17. **Homework**（P32）——Design a neighborhood of your living place, draw and write a report。
18. **首尾呼应**（P33）——回到真实地图（Bingang Street/Longyan Street/Zhongshan Road）。

## 三、可复用套路（PPTskill 模板规则）

### 1. 结构范式：真实情境听说课 12 步
```
封面 → 情境建立(外国学生/真实人物探访) → 街名/地名导入
→ 句型呈现 → 听力任务(判断√×+匹配) → 句型操练(场所逐一练)
→ 听力任务2(对话补全) → Pair work(地图限时) → Chain Game(接龙)
→ 情境推进 → 听力任务3(方位匹配) → 方位介词讲解
→ 听力任务4(填空) → Memory Test → Group work(小组分工产出)
→ Summary → Homework → 首尾呼应(回到真实地图)
```

### 2. 核心设计原则
- **情境人物贯穿**：Mike 探访校园周边串起所有环节，任务真实有目的，不是孤立练习
- **听先于说**：每环节先听力输入（判断/匹配/填空），再口语输出
- **词汇在任务中学**：6 个场所词通过听判断+句型操练自然习得，不单独背
- **游戏化操练**：Chain Game、Memory Test 增加趣味与参与度
- **小组分工**：ask/answer/reporter/designer 明确角色，保证人人参与
- **限时管理**：每个活动标注时间（1-10分钟），把控课堂节奏
- **首尾呼应**：封面地图 → 结尾真实地图，情境完整闭环
- **产出可见**：小组设计社区并展示，学习成果外化

### 3. 听说课听力任务链（本课核心）
- 任务1 听判断（√/×）+ 匹配 → 建立场所词汇
- 任务2 听对话补全（挖空）→ 巩固询问句型
- 任务3 听方位匹配 → 引入方位介词
- 任务4 听填空（2b）→ 巩固方位介词
四层递进：词汇 → 句型 → 方位 → 综合。

### 4. 句型操练设计
- 给句型框架："There is a ___ near here. We can ___."
- 每个场所一页，配图 + 用途短语（bank→take out money）
- 从机械操练到半开放（挖空）再到开放（Pair work 用自己地图）

### 5. 活动与游戏
- **Chain Game 接龙**：第1人"There is a supermarket"→第2人累加"and two banks"→... 训练 there be 就近原则
- **Memory Test**：快速记忆地图 → 回答 Is/Are there...? Where...?
- **Group work 分工**：ask/answer/reporter/designer，限时产出社区设计图

### 6. 情境推进技巧
- 从"学校周边"→"pay phone（学生不能带手机）"→"其他学校"→"设计理想社区"，层层递进
- 每个新任务都有情境动机（Mike 想知道更多、Tracy 要带他参观）

### 7. 版式与视觉
- 4:3 传统版式
- 大量地图/街景/场所图标配图，视觉真实
- 表格呈现场所清单
- 每页配图+文字双栏，标题醒目
