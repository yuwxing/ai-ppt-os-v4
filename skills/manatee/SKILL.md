## 二、制作过程还原（23 页流程）

1. **封面**（P1）——单元大标题 + 课时小节 + 教师署名 + 主题配图。规矩：公开课必备"单元名 + 教师名"，配高清环保图。
2. **学习目标**（P2）——3 条目标编号呈现：阅读技能 / 重要结构 / 节能表达。配图点缀。
3. **人物导入**（P3）——介绍 Amy Winterbourne，"She is an unusual woman. **?** What makes her unusual?" 用大问号制造悬念。
4. **图片切入**（P4）——点题句：Her house makes her unusual. It is **made from trash**.
5. **主题呈现**（P5）——It is a house of trash 垃圾屋!（作品感大字标题）
6-9. **阅读四任务**（P6-9）——
   - Task 1 扫读 T/F 判断
   - Task 2 细读寻读回答
   - Task 3 听读填表（Old glass bottles / The roof / The fence / Old TVs）
   - Task 4 朗读质疑，引出 Key Structures：make/build A out of B
10. **语法聚焦**（P10）——be made **from / of / in / by / into** 五种用法对比。
11. **Exercise 1**（P11）——选词填空 from/of/in/by/into。
12. **Exercise 2**（P12）——交际语境选择题。
13. **意义追问**（P13）——Why does Amy want to recycle the trash? → 节能 / 环保 / 拯救地球。
14. **讨论**（P14）——What can we do to save energy? 提供 A/B 对话句型支架。
15-16. **写作任务**（P15-16）——以 How we should save energy 写 80 词短文，附要点提示 + 连接词支架（First.../Second.../At last...；First of all.../What's more.../Last but not least...）。
17-18. **Summary**（P17-18）——Key structures 总结 + Conjunctions 连接词 + How to save energy 行动清单。
19. **情感升华**（P19）——Let's try our best to save energy and protect our home.
20. **名言激励**（P20）——Never put off till tomorrow what you can do today. Take action now!
21. **（过渡页）**
22. **Homework**（P22）——必做（写作）+ 选做，分层作业。
23. **致谢**（P23）——Thanks for listening!

## 三、可复用套路（PPTskill 模板规则）

### 1. 结构范式：公开课阅读课 12 步
```
封面 → 学习目标 → 悬念导入 → 图片点题 → 主题呈现
→ 阅读任务链（扫读→寻读→听读→朗读质疑，4 个 Task）
→ 语法聚焦 → 机械练习 → 交际练习
→ 意义追问 → 讨论支架 → 写作输出 → 总结 → 情感升华 → 名言 → 分层作业 → 致谢
```

### 2. 阅读课任务链设计（核心卖点）
- **四任务递进**：Skimming（扫读 T/F）→ Scanning（寻读问答）→ Listening（听读填表）→ Read aloud（朗读质疑）。
- 每个 Task 都有明确指令 + 中文注释，降低学生认知负荷。
- 任务之间从"理解"到"运用"层层递进。

### 3. 语法处理：从文本中来，到练习中去
- 先通过阅读语篇自然呈现 `make/build A out of B`。
- 再对比辨析 `be made from/of/in/by/into`（配中文提示）。
- 最后用"选词填空 → 语境选择"两级练习巩固。

### 4. 写作支架
- 给话题 + 要点 + 词数要求。
- 给连接词模板：`First... / Second... / At last...`；`First of all... / What's more... / Last but not least...`。
- 写作前必有讨论环节提供语言储备。

### 5. 情感教育升华（公开课亮点）
- 从"语言知识"上升到"价值观"：节能 → 环保 → 保护地球。
- 用名言警句收尾：Never put off till tomorrow what you can do today.
- 配套素材：Heal The World.mp3（升华配乐）、Earth Story.flv（导入视频）。

### 6. 版式与视觉
- 宽屏 16:9。
- 每页配图或图标点缀，避免纯文字。
- 标题页大字 + 图文并茂；练习页留白充足便于书写。
- 中文注释辅助英文（教师授课可用）。
