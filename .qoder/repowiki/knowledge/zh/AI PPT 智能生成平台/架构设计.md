- **容器化编排**：利用 `deployment/docker-compose.yml` 定义后端（FastAPI）、前端（Vite/React）及 Redis 中间件的依赖关系与网络隔离（`pptv3`），并通过共享卷持久化输出文件与数据库。
- **请求路由与代理**：`deployment/nginx.conf` 作为入口网关，将 `/api/` 路径反向代理至后端服务，其余静态资源由前端容器处理，实现了前后端在部署层面的解耦与统一访问。
- **跨模块通信契约**：前端通过 `axios` 拦截器统一注入 JWT 令牌，后端基于 FastAPI 中间件处理 CORS 及认证校验，确立了以 RESTful API 为核心的无状态交互模式。
